## 7. Non-conformities and open items

These are recorded as found. None was hidden by the build.

**7.1 Artifacts are unsigned.** `Get-AuthenticodeSignature` reports `NotSigned`
for both executables. There is no publisher identity, and Windows SmartScreen
will warn on first run. Integrity rests on the SHA-256 values in §3 until a
certificate is configured.

**7.2 Source tree was not committed at build time.** 36 paths were modified or
untracked. The artifacts correspond to that working tree, not to `7f34789` alone.
Commit before publishing so the hashes map to a reviewable revision.

**7.3 Dev-dependency vulnerabilities.** 13 advisories in test/build tooling
(§6). Tracked, not fixed in this release.

**7.4 No automated end-to-end GUI test.** The packaged app was verified by
launching it and confirming a window; the IPC path-restriction rules are covered
by typecheck and review only. One manual encrypt → decrypt round trip in the
packaged app is still required before publishing.

**7.5 JavaScript key erasure is best-effort.** Buffers are zeroed on all paths,
including KDF failure, but the runtime may copy memory.

**7.6 No brute-force rate limiting.** Inherent to an offline tool; documented in
`docs/SECURITY.md`.

**7.7 Video metadata reader limits.** A track header beyond 8 MB of container
metadata, or a Matroska file with unknown-size clusters before its track list,
is rejected as unreadable rather than allowed.
